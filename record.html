🎙️ Tempat tenang. Matikan kipas/AC jika bisa. Jarak mulut ke laptop ±20 cm.

Cara memasang rekaman ke gim
  1. Klik ⬇ Unduh semua rekaman. File SataMart_audio.zip berisi file suara dan list.js.
  2. Ekstrak ZIP itu. Isinya dimasukkan ke folder assets/audio di gim (timpa list.js yang lama).
  3. GitHub: buka folder assets/audio di repository → Add file → Upload files → seret semua file hasil ekstrak → Commit changes.
  4. Buka gim, klik tombol Listen. Suara Ibu/Bapak yang akan terdengar. Kalimat yang belum direkam tetap memakai suara perangkat.

Rekaman tersimpan di browser ini sampai Ibu/Bapak menghapusnya, jadi boleh dicicil di beberapa waktu. Jika teks di gim diubah, kalimat itu perlu direkam ulang karena nama filenya ikut berubah.
